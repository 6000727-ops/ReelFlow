# ReelFlow v0.2

Автоперелистывание коротких роликов Instagram Reels, VK Клипы, VK Видео и ВКонтакте.

**Режим приватности:** приложение не считывает содержимое экрана, текст, пароли или сообщения. Служба специальных возможностей получает только события смены приложения и листания и умеет отправить жест свайпа вверх. Разрешение на Интернет не используется.

## Как работает

1. Включи службу специальных возможностей ReelFlow в системных настройках Android.
2. В ReelFlow выбери приложения и интервал от 10 до 180 секунд.
3. Открой ролики в Instagram или VK и нажми ▶ в плавающей панели справа.
4. Останови нажатием Ⅱ. При выходе из выбранного приложения служба ставит автолистание на паузу.

Важное ограничение: точное окончание ролика не определяется, используется таймер. Приложение не проверялось на физическом телефоне.

## Сборка

GitHub Actions → Build Android APK → артефакт ReelFlow-APK (APK внутри ZIP). Файл подписан отладочным ключом GitHub Actions, не предназначен для публикации в Google Play. Сборка прошла проверку компиляции, но не является проверкой безопасности Google Play.

**Установка может быть заблокирована Google Play Защитой даже после уменьшения разрешений, поскольку сама служба Accessibility остаётся чувствительным разрешением. Не отключайте защиту устройства ради установки.**
