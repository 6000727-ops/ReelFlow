# ReelFlow

Android-приложение для локального автоматического перелистывания коротких видео в Instagram Reels, VK Клипах, VK Видео и ВКонтакте.

### Возможности
- Ручной запуск / пауза через плавающую панель
- Свайп вверх по таймеру: 10–180 секунд
- Экспериментальное определение окончания, когда плеер предоставляет доступный индикатор прогресса
- Отдельные переключатели для Instagram, VK Клипы, VK Видео и ВКонтакте
- Остановка при выходе из выбранного приложения и выключении экрана
- Без разрешения на Интернет, рекламы и отправки данных

**Важно:** Если социальная сеть не раскрывает длительность ролика через Android Accessibility, точное определение его окончания невозможно, поэтому используется указанный интервал. На отдельных экранах VK или Instagram переключение может не работать; приложение требует проверки на реальном устройстве.

### Установка
1. Скачайте `ReelFlow-APK` из GitHub Actions → успешная сборка.
2. Разархивируйте артефакт, установите `app-debug.apk`.
3. В приложении нажмите «Специальные возможности» и включите ReelFlow.
4. Перейдите в Reels / Клипы и нажмите ▶ в плавающей панели.

### Сборка
GitHub Actions автоматически запускает сборку при загрузке кода. Для ручного запуска: Actions → Build Android APK → Run workflow. Можно также открыть проект в Android Studio (JDK 17, Gradle 8.9, Android SDK 35).
